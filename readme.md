# modul-cotiza
proyecto para crear una sub-página dentro de la web de modul, para que uno pueda diseñar una tiny modul módulo por módulo, terminaciones, etc. La idea es que sea intuitiva, fácil y rápida, que pueda correr en plataformas móviles y de escritorio, teniendo a la vez una visualización 3D en tiempo real del modelo, y una estimación del precio final.
